# 데스크톱 펫 계획서 — 피아노 고양이

## 1. 만들 것
바탕화면 위에 떠 있는 검은 고양이 펫. 고양이는 피아노 앞에 앉아 있다.

| 상황 | 고양이 모습 |
|---|---|
| 평소 (깨어 있음) | 한 손 든 그림. 몇 초마다 왼손·오른손을 바꿔서 손을 흔드는 것처럼 보임 |
| 클릭했을 때 | 두 손 든 그림으로 잠깐 바뀌었다가 평소 모습으로 돌아옴 |
| 1분 동안 안 만졌을 때 | 눈 감은 그림으로 바뀌어 잠듦. 클릭하면 깨어나서 두 손을 듦 |
| 마우스로 끌 때 | 바탕화면 아무 데로나 옮겨짐 |
| 오른쪽 클릭 | 작은 메뉴가 나오고 "종료"를 누르면 꺼짐 |
| 키보드를 칠 때 (추가) | 키보드 왼쪽 키 → 화면 왼쪽 손이 건반을 침, 오른쪽 키 → 화면 오른쪽 손이 건반을 침. 잠들었으면 깨어남 |

- 크기: 약 250 × 250 픽셀
- 창 테두리 없음, 배경 투명 → 고양이만 보임
- 항상 다른 창보다 맨 위에 보임
- 소리 없음

## 2. 어디서 돌아가는지
- Windows 바탕화면 위 (브라우저 안이 아님)
- **Electron**으로 만든다. 웹페이지(HTML·CSS·JavaScript)를 바탕화면 창으로 띄워 주는 프로그램이다.
- 작업 폴더: `week-03/desktop-pet/` (편의점 게임 `week-03/index.html`은 건드리지 않음)
- 실행 방법: `week-03/desktop-pet` 폴더에서 `npm start`

## 3. 재료
| 재료 | 설명 | 상태 |
|---|---|---|
| `week-03/art/sheet.png` | 고양이 그림 4칸 (1254 × 1254, 배경 투명) | 있음 |
| Node.js | 이미 설치돼 있음 | 있음 |
| Electron (npm 패키지) | 바탕화면 창을 만드는 도구 | **설치 필요 — 설치 전에 물어보기** |
| uiohook-napi (npm 패키지, 추가) | 다른 프로그램을 쓰는 중에도 키를 눌렀는지 알려 주는 도구 | 허락받고 설치함 |

그림 칸 순서 (한 칸 약 627 × 627):

| 왼쪽 위 | 오른쪽 위 |
|---|---|
| ① 두 손 들기 (클릭) | ② 오른손 들기 (평소) |
| **왼쪽 아래** | **오른쪽 아래** |
| ③ 왼손 들기 (평소) | ④ 눈 감기 (잠) |

만들 파일 (예정):
- `package.json` — 프로젝트 이름, `npm start` 명령
- `main.js` — 바탕화면 창 만들기 (투명, 테두리 없음, 맨 위, 오른쪽 클릭 메뉴)
- `index.html` — 고양이 그림을 보여 주는 화면
- `pet.js` — 손 흔들기, 클릭, 잠자기, 끌기
- `.gitignore` — `node_modules` 폴더를 GitHub에 안 올리게 함

## 4. 단계

### 0단계 · 준비
- `week-03/desktop-pet/` 폴더, `package.json`, `.gitignore` 만들기
- 허락을 받은 뒤 Electron 설치 (`npm install --save-dev electron`)
- **확인할 것**
  - [ ] `week-03/desktop-pet` 안에 `node_modules` 폴더가 생겼나요?
  - [ ] `git status`를 했을 때 `node_modules`가 목록에 없나요?
- **커밋**: `week-03: 데스크톱 펫 준비 (Electron, 계획서)`

### 1단계 · 투명 창에 고양이 띄우기
- 250 × 250 크기, 테두리 없음, 배경 투명, 항상 맨 위인 창을 만들기
- 그림 한 칸(② 오른손)만 보이게 하기
- **확인할 것**
  - [ ] `npm start`를 하면 바탕화면에 고양이가 나오나요?
  - [ ] 고양이 둘레의 바탕화면이 그대로 비쳐 보이나요? (네모난 흰색·검은색 배경이 없나요?)
  - [ ] 메모장을 열어 고양이 위로 겹쳐 놓아도 고양이가 앞에 보이나요?
  - [ ] 고양이 귀 끝부터 피아노 아래까지 잘린 곳 없이 다 보이나요?
  - [ ] 옆 칸 그림이 가장자리에 조금이라도 삐져나와 보이지 않나요?
- **커밋**: `week-03: 데스크톱 펫 - 투명 창에 고양이 띄우기`

### 2단계 · 오른쪽 클릭 → 종료
- 꺼지지 않는 창은 불편하니까 끄는 방법을 먼저 만든다
- 고양이를 오른쪽 클릭하면 "종료" 메뉴가 나온다
- **확인할 것**
  - [ ] 고양이를 오른쪽 클릭하면 "종료"가 적힌 메뉴가 나오나요?
  - [ ] "종료"를 누르면 고양이가 사라지나요?
  - [ ] 종료한 뒤 터미널에 다시 명령을 입력할 수 있나요? (프로그램이 완전히 끝났나요?)
- **커밋**: `week-03: 데스크톱 펫 - 오른쪽 클릭 종료 메뉴`

### 3단계 · 평소에 손 흔들기
- ② 오른손 칸과 ③ 왼손 칸을 몇 초마다 번갈아 보여 준다
- **확인할 것**
  - [ ] 30초 동안 가만히 지켜보면 왼손·오른손이 번갈아 바뀌나요?
  - [ ] 그림이 바뀔 때 고양이 몸과 피아노가 제자리에 있나요? (옆이나 위아래로 밀리지 않나요?)
- **커밋**: `week-03: 데스크톱 펫 - 평소 손 흔들기`

### 4단계 · 클릭하면 두 손 들기
- 왼쪽 클릭하면 ① 두 손 칸을 잠깐 보여 주고 평소 모습으로 돌아온다
- **확인할 것**
  - [ ] 고양이를 한 번 클릭하면 두 손을 드나요?
  - [ ] 클릭하고 2초쯤 지나면 다시 손 흔들기로 돌아오나요?
  - [ ] 10번 빠르게 연달아 클릭한 뒤에도 2초쯤 지나면 손 흔들기로 돌아오나요?
- **커밋**: `week-03: 데스크톱 펫 - 클릭하면 두 손 들기`

### 5단계 · 1분 동안 안 만지면 잠자기
- 마지막으로 만진 뒤(클릭·끌기) 1분이 지나면 ④ 눈 감은 칸으로 바뀐다
- 잠든 동안에는 손을 흔들지 않는다
- 잠든 고양이를 클릭하면 깨어나서 두 손을 들고, 다시 평소 모습이 된다
- 확인하는 동안에는 시간을 10초로 줄여서 시험해 보고, 다 되면 1분으로 돌려놓는다
- **확인할 것**
  - [ ] (10초로 줄인 상태에서) 10초 동안 가만히 두면 눈을 감나요?
  - [ ] 눈 감은 동안에는 손을 흔들지 않나요?
  - [ ] 잠든 고양이를 클릭하면 눈을 뜨고 두 손을 드나요?
  - [ ] 깨운 뒤 다시 10초 동안 가만히 두면 또 눈을 감나요?
  - [ ] 시간을 1분으로 돌려놓은 뒤, 1분 동안 가만히 두면 눈을 감나요?
- **커밋**: `week-03: 데스크톱 펫 - 1분 지나면 잠자기`

### 6단계 · 끌어서 옮기기
- 마우스로 누른 채 움직이면 창이 따라 움직인다
- 조금만 움직였을 때는 "클릭"으로, 많이 움직였을 때는 "끌기"로 구분한다 (끌고 놓을 때마다 두 손을 들지 않게)
- **확인할 것**
  - [ ] 고양이를 화면 왼쪽 위 끝까지 끌어 옮길 수 있나요?
  - [ ] 고양이를 화면 오른쪽 아래 끝까지 끌어 옮길 수 있나요?
  - [ ] 끌다가 마우스를 놓았을 때 두 손을 들지 않나요?
  - [ ] 끌지 않고 그냥 클릭하면 여전히 두 손을 드나요?
  - [ ] 옮긴 자리에서 오른쪽 클릭하면 여전히 "종료" 메뉴가 나오나요?
  - [ ] 50초쯤 가만히 두었다가 끌어 옮기면, 그 뒤 1분이 지나야 잠드나요? (옮기자마자 잠들지 않나요?)
- **커밋**: `week-03: 데스크톱 펫 - 끌어서 옮기기`

### 8단계 · 키보드 따라 치기 (추가)
- 키를 누르면 메인 프로그램(`main.js`)이 키보드 왼쪽 키인지 오른쪽 키인지만 고르고, 키 번호는 바로 버린다
- 화면(`pet.js`)에는 `left` / `right` 만 보낸다
- 누른 횟수만 메모리에서 센다 (파일에 저장하지 않음, 끄면 사라짐)
- **확인할 것**

  - [ ] 메모장에서 J·K·L 을 치면 화면 오른쪽 손이 건반 위로 내려가나요?
  - [ ] 키를 멈추고 1초쯤 지나면 다시 손 흔들기로 돌아오나요?
  - [ ] 잠든 고양이가 키를 치면 깨어나나요?
  - [ ] `main.js`·`pet.js`·`preload.js` 어디에도 키를 파일에 쓰거나 인터넷으로 보내는 코드가 없나요?
- **커밋**: `week-03: 데스크톱 펫 - 키보드 따라 치기`

## 5. 하지 말 것
- 소리 넣지 않기
- 어떤 키를 눌렀는지는 저장도 전송도 하지 않고, 몇 번 눌렀는지만 센다
- 저절로 피아노 치는 동작은 만들지 않기 — 건반은 내가 키보드를 칠 때만 친다
- `week-03/index.html` (편의점 게임) 건드리지 않기
- `week-03` 밖, `desktop-pet` 밖에 파일 만들지 않기 (`plan.md` 제외)
- Electron 말고 다른 프로그램·패키지를 묻지 않고 설치하지 않기
- `node_modules` 폴더 커밋하지 않기
- `sheet.png`를 고치거나 이름 바꾸지 않기 (칸을 나눈 그림이 필요하면 새 파일로 만들기)
- 한 단계를 확인하기 전에 다음 단계로 넘어가지 않기
- GitHub에 올리기(push)는 내가 하자고 할 때만
